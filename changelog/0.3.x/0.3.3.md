# 0.3.3 — 2026-09-19

## Changed

- **`createApp` declares `sessionMode: 'stateless'`** in `src/index.ts` ([#23](https://github.com/cyanheads/workflows-mcp-server/issues/23)) — the HTTP session posture is stated in code instead of depending solely on `MCP_SESSION_MODE`; the env var still overrides when set to a meaningful value.
- **Tool argument validation changes for every call, via mcp-ts-core 0.13.1–0.13.6** — an out-of-schema argument is rejected as `InvalidParams` (`-32602`) rather than the prior classification; the rejection's `content[]` carries a `Recovery: <hint>` line derived from the schema and closes with `(reason … · not retryable)` when the error data carries those fields. Before validation runs, a client-added root key is dropped, a case-style key alias is rewritten, and a JSON-stringified array that fails to parse is repaired and retried once.

## Fixed

- **`WorkflowIndexService`'s `fs.watch` handle and debounce timer are released on shutdown** ([#25](https://github.com/cyanheads/workflows-mcp-server/issues/25)) — `createApp({ teardown })` calls the new `shutdownWorkflowIndexService()`, so the process now exits after `SIGTERM` instead of staying resident until `SIGKILL`.
