# 0.5.1 — 2026-11-21

## Changed

- **Bun** now requires version 1.4.4 or later.
- **Framework tooling** rejects invalid arguments in `devcheck` and `release:github`. The upstream MCPB cleaner replaces the local SDK skills workaround and extends agent doc cleanup to `AGENTS.md` and `CLAUDE.md` at every dependency package root.

## Fixed

- **`WORKFLOWS_DIR`** initialization finishes before transport startup. If the directory cannot be created, startup fails with a configuration error that names the resolved path. The Docker image provides a writable default directory. ([#36](https://github.com/cyanheads/workflows-mcp-server/issues/36))
- **Workflow tags** are trimmed and blank entries are dropped on create, draft overwrite, and read. Tags retain their case and order, and existing YAML files stay intact. The `workflows-guide` skill documents the new behavior. ([#39](https://github.com/cyanheads/workflows-mcp-server/issues/39))
