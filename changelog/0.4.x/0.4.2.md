# 0.4.2 — 2026-10-25

## Changed

- **Framework input and error handling:** Tool arguments gain representation repairs from mcp-ts-core 0.13.14; error text gains Markdown escaping from 0.13.16.
- **MCPB bundles** exclude development sources, tests, scripts, docs, coverage, and editor configuration.
- **Development tooling** synchronizes framework guidance and corrects audit attribution when a patched direct dependency shares an advisory block with a vulnerable transitive copy.
- **Framework skills:** `add-test` 1.10, `add-tool` 2.35, `api-auth` 1.7, `api-canvas` 2.9, `api-config` 1.27, `api-context` 2.13, `api-errors` 1.24, `api-mirror` 1.6, `api-telemetry` 1.22, `api-testing` 1.16, `api-utils` 2.19, `api-workers` 1.10.
- **Framework workflows:** `design-mcp-server` 2.33, `field-test` 2.23, `git-wrapup` 1.31, `orchestrations` 1.14 (`greenfield-build` 1.5), `polish-docs-meta` 2.24, `release-and-publish` 2.25, `security-pass` 1.14, `tool-defs-analysis` 1.9.

## Fixed

- **Workflow metadata** renders as literal text across all five tools, preserving punctuation and multiline names; authored global instructions retain their Markdown formatting.
- **`WATCHER_DEBOUNCE_MS`** rejects fractions, negative values, and values above 2147483647 at startup.
- **Regression fixtures** isolate explicit duplicate-index rebuilds and load framework imports before config test timers begin.
